# Como contribuir

Bugs, sugestões, documentação e pull requests são bem-vindos!

1. Faça um fork e crie uma branch para sua mudança.
2. Instale as dependências descritas no README.
3. Execute `python3 -m unittest discover -s . -v` em uma sessão gráfica de teste.
4. Verifique visualmente o app e descreva o resultado no pull request.

Ao relatar um problema, informe distribuição, versão do KDE/Qt, sessão
Wayland ou X11, quantidade de monitores e passos para reproduzir. Use apenas
texto fictício em capturas de tela.

Para mudanças na interface, teste as sete cores, tamanho mínimo,
redimensionamento, seleção de texto, copiar/colar, múltiplas notas e
recolhimento/restauração nas quatro bordas. Para o instalador, confirme que
um atalho usado por outro aplicativo nunca é sobrescrito.

Não inclua credenciais, arquivos de configuração pessoais ou conteúdo de notas.
Ao enviar contribuições, você concorda que elas sejam distribuídas sob a
licença MIT do projeto.
